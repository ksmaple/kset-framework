# kset-framework-file-relations

> 执行约束以 [项目规则](../../rules/kset-framework-project-rules.md) 为准；项目事实见 [project-spec.md](../../../docs/overview/design/project-spec.md)。本规范不得覆盖或放宽项目规则。

## 触发条件

**启用**：当前任务命中规范 `kset-framework-file-relations` 的适用范围时读取；适用于按指定页面或路由梳理组件、状态、接口、样式和资源并生成 HTML 报告。

**不启用**：完整业务时序、需求设计、接口文档和业务源码修改属于其他角色。

## 核心规则

R000: 本规范仅在 kset-framework（proj=kset-framework）所属项目仓库及其工作树使用，跨项目任务须使用目标项目自己的规则与规范
R001: 开始前读取 project-spec 中与目标页面相关的技术栈、路由、目录和项目约定；仅检查任务相关源码、配置及项目文档，不读取依赖包、构建产物或生成源码
R002: 输入只有文件名或路由且可匹配多个页面时，列出候选项目相对路径并确认目标；不得凭同名文件推断归属
R003: 以目标页面文件为中心，默认只展示一跳直接关联；二跳节点仅在有可定位依据且与该页面功能有关时纳入，并标明间接关系
R004: 按实际功能对路由、页面、子组件、组合式函数或 Hook、状态、API、样式和资源文件分组；同一文件可参与多个功能，但图中只保留一个文件节点
R005: 连线须区分路由指向、渲染、导入、事件与属性、状态读写、接口请求、导航及资源使用；静态导入不得写成已发生的运行调用
R006: 每条连线须注明方向、关系类型和可定位的项目相对路径与行号；证据不足的关系列为待核实，不画成已证实连线
R007: 默认排除第三方依赖、通用框架内部文件和与页面功能无关的引用；不得为凑满图形扩大扫描范围
R008: 报告标题使用目标文件名，顶部同时显示项目相对路径、关联范围与整理日期；同名报告使用包含相对路径的唯一文件键
R009: 按 references/file-relations-format.md 生成 `docs/{module}/reports/file-relations-{page-key}.html`；`page-key` 由目标页面的项目相对路径生成，须按项目规则 R140 保持唯一并核对现有文件归属；用户指定正式交付路径时遵从用户要求并按项目规则分类
R010: 以 references/network-page.html 为样式底稿，页面、画布、面板和控件以近黑与深灰为主，功能色仅用于节点与关系强调；主视图为可平移的交互画布，节点有稳定的初始布局且可拖拽，按文件角色用文字标签，连线用箭头和文字标明关系，不仅靠颜色传达含义
R011: HTML 须支持功能与关系筛选、文件搜索、缩放、画布平移、节点拖拽与点击展开可关闭的详情；桌面与触屏均可操作，拖动节点时实时更新连线，拖拽不得误触详情，复位须恢复初始布局和缩放
R012: 图下须列出全部纳入的文件、关系依据、未核实项及范围边界，图中编号与说明双向定位；不得将代码可见关系宣称为线上运行事实
R013: 报告须为无需外部 CDN 的单文件离线 HTML；文件名、路径和说明写入 HTML 时须转义，不插入从源码读取的可执行片段或敏感配置值
R014: 更新已有报告时重新核对受影响关联，保留仍有效的人工核实说明，并同步更新图、关系清单和编号
R015: 本规范只生成文档并进行静态核对，不修改业务源码，不执行编译、测试、启动或部署
R016: 写入前按 `.claude/rules/kset-framework-project-rules.md` R070a–R070o 与 R106 核对工作树及文件分类；提交和推送遵守该规则 R088–R089
R017: 输出前核对节点文字、功能色标、箭头方向、证据链接、筛选、缩放、画布平移、节点拖拽、详情展开与关闭及桌面和移动端布局；按项目规则 R053–R054、R056–R057 完成任务门禁

## 工作流

```text
Step 0: 确认页面文件或路由、项目相对路径及关联范围
Step 1: 从路由与目标页面出发，查找一跳关联及有依据的相关二跳文件
Step 2: 按功能归并文件节点，逐条记录关系类型、方向与路径行号
Step 3: 依照格式说明和 HTML 底稿生成黑底交互画布报告，替换全部示例内容
Step 4: 静态核对图与关系清单，检查平移、拖拽、展开详情及不同屏宽后交付
```
