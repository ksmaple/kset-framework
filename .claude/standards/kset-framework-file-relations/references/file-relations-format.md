# 前端页面文件关联 HTML 报告格式

> 默认输出 `.claude/design/file-relations/{page-key}.html`。`page-key` 由目标页面在所属项目内的完整相对路径生成，须遵守项目规则 R140 的单文件名片段与同名保护；用户指定其他路径时按项目规则判断本地协作或正式交付。

## 输入与范围

记录目标项目、页面文件的项目相对路径、对应路由（若存在）、关联深度、涉及功能及整理日期。只有文件名或路由且存在多个候选时，先确认具体页面。默认只纳入一跳关联；二跳须与目标功能直接相关并有源码或配置依据。

## 网状图

以目标页面为唯一中心节点，按功能安排周边文件。提供可平移的黑底交互画布；节点有稳定的初始坐标，允许用户临时拖动并在复位时恢复。功能用稳定且可区分的色标，文件角色用文字标签。箭头指向实际引用或数据流目标，实线表示直接关系，虚线表示有依据的间接关系；拖动节点时连线须跟随，不得把 `import` 当作运行调用。跨功能边保留实际两端，不为排版复制文件节点。

节点最少包含稳定编号、文件名、项目相对路径、角色、功能、深度和一句职责。关系最少包含稳定编号、来源节点、目标节点、类型、直接或间接、依据 `路径:行号` 与简短说明。路由、渲染、导入、事件与属性、状态读写、接口请求、导航、样式与资源使用按实际证据选择；不能确定的关系放在“待核实”清单。

## 页面结构

1. 顶部紧凑列出目标文件名、相对路径、路由、范围和日期。
2. 主区域是深色交互画布，提供文件搜索、功能与关系筛选、缩放和复位；空白处拖动可平移画布，节点可拖拽，默认显示直接关联，二跳由深度选项展开。
3. 点击节点展开可关闭的详情，显示职责、关联方向、关联文件和可定位证据；拖拽不触发详情。图下的完整文件及关系清单包含同一编号，筛选图形时仍保留全部清单和依据，点击文件链接可定位图中节点。
4. 末尾列出排除范围、待核实项与“代码可见不等于线上运行”的状态说明。

以同目录 `network-page.html` 为结构参考，页面、画布、面板和控件以近黑与深灰为主；用高对比文字与少量多功能色标区分关系，不使用大面积亮色底。替换底稿中的全部示例文件、关系与路径；没有证据的示例项须删除。图上名称保持短，完整路径放在详情和图下清单。文件名、路径及说明作为文本插入或经 HTML 转义，不把源码片段拼入脚本。

## 验收

核对每条图中连线与图下关系清单一一对应，方向和类型有依据；同名文件不混淆，筛选后节点与连线同步变化，拖拽节点时连线跟随，拖拽不误触详情，复位恢复初始布局和缩放。离线打开 HTML，在桌面和移动屏宽检查文字、颜色对比、平移、详情展开与关闭及横向滚动。
